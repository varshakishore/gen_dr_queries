# Mechanistic plausibility (acidified systems)
- In aqueous chemistry, nitrite is not strongly reactive by itself; in acidic or warmed media nitrite generates nitrous acid (HNO2). At higher pH, HNO2 is in equilibrium with its anhydride N2O3, which can act as a nitrosating agent and react with sulfur-containing species.
